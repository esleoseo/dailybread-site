이 저장소의 HTML은 **직접 고치지 않는다.** 원본은 앱 저장소의 `BibleDoodle/Legal/` (문서)와 `LegalInfo.json` (운영자 정보)이고,
`node tools/legal/build_site.mjs --out <이 저장소 경로>`로 다시 만들어 올린다.
